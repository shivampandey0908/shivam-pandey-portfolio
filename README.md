# Shivam Pandey — Portfolio

A modern animated portfolio built with React, Vite, Framer Motion and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Included
- Responsive dark portfolio UI
- Smooth section navigation and active-section indicator
- Scroll-triggered reveal animations
- Hero entrance animations and floating UI cards
- Animated project/skills/achievement cards
- Certificate lightbox
- Downloadable cleaned CV with Shivam's active links
- Profile photo and CodeBuild certificate
- Live links for EduInsight AI and InterviewVerse

## Deploy
The project is Vercel-ready. Import the folder/repository and use the default Vite build settings.
